These guidelines define how this dashboard classifies, measures and displays venues that facilitates conversion between crypto and fiat.

The aim is a neutral, transparent comparison. Every figure on the dashboard is tagged with **where it came from** and **when it was last verified**, so you can judge a number for yourself rather than taking a single blended figure on faith.

## What the dashboard covers

We track venues that let users move between fiat and crypto, across two kinds of data:

- **Informational** — supported fiats, payment methods, KYC requirements, custody model, settlement.
- **Trading** — live rates, available liquidity, observed spreads, and (where published) volume.

A venue can be an on-ramp, an off-ramp, or both. We do not rank venues by a single score; we surface the underlying facts and let you filter to what matters for your route.

## The goal

Consistent classification and measurement, so that a number means the same thing across venues — or, where it cannot, so the difference is **labeled rather than hidden**. Where a value is approximated or not disclosed, we say so directly.

> This methodology is a work in progress. It evolves as we add venues and tighten measurement; material changes are made in the open via the project's commit history.
